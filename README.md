# 118 Lendas — GTA San Andreas PC

[Baixar o mod ZIP](https://github.com/pietrovargasaraujo-rgb/gtq/raw/refs/heads/main/118_Lendas_CLEO4_ModLoader_ALPHA.zip)

Extraia o ZIP e copie as pastas **CLEO** e **modloader** para a pasta onde está `gta_sa.exe`. Requer GTA SA clássico de PC, CLEO 4 e Mod Loader 0.3.7 funcionando.

O mapa offline com os 118 pontos e horários está em `modloader/118_Lendas/Mapa_das_aparicoes.html`.

**Versão ALPHA experimental:** modelos 3D simples e estáticos, com variações por família, diferentes da imagem de referência. Inclui 118 sons sintetizados. Os arquivos e a lógica passaram por verificações automatizadas, mas o mod **não foi testado dentro do GTA SA**. Não há garantia de ausência de erros.
